# 日序 · Personal Planner

黑色极简个人计划与记账网站，无第三方运行依赖。

## 启动

在仓库目录运行 `npm run dev`，HTTP 服务端口为 3000。需要 Python 3；验证使用 Node.js：`npm test`、`npm run check`。

## 功能

- 每周七列日期计划，可切换周、添加任务；任务右划完成、左划未完成，也可用按钮操作与撤销状态。
- 先设置总资产，再按日期记录开销并选择日常分类。以人民币显示金额，内部以分计算；周统计从周一开始，月统计按自然月，日期依据浏览器本地时区。
- 剩余资产为起始总资产减去全部记录的开销，允许负余额。修改总资产不会清除开销记录。
- 数据保存在当前浏览器的 localStorage，支持 JSON 备份导出与导入；导入前会确认替换。

此版本不含账号、云同步或自动部署。浏览器清除站点数据会删除本地记录，请定期导出备份。
