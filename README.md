# 日序 · Personal Planner

纯黑背景、蓝色控件的个人计划网站，无第三方运行依赖。

## 启动和验证

在仓库目录运行 `npm run dev`，HTTP 服务端口为 3000，需要 Python 3。使用 Node.js 运行 `npm test` 和 `npm run check`。

## 计划

- 每周七列日期，可切换周、添加或编辑任务。新任务必须填写开始和结束时间，结束晚于开始；卡片展示完整时间区间。
- 旧任务不丢失，缺少结束时间会明确标记，可用「编辑」补齐。
- 点击或轻触任务卡片标记完成，卡片变绿，右上角显示小对号和「已完成」文字；再次点击恢复待办和任务名称的原有配色。
- 未完成任务显示原有事件配色，不显示红色。旧版标记为未完成的任务也按事件颜色展示，保留记录。
- 编辑和删除独立于完成按钮；键盘可聚焦卡片并使用 Enter/Space 切换状态。横向滑动看板只切换可见日期，不改变任务状态。
- 今日进度只统计当天任务。同名任务在不同日期保持同色。

## 旧版记录兼容

开销栏目、资产设置、记账入口及统计界面已移除。旧版备份与账号记录中的资产和开销字段继续保留，便于备份兼容，不执行历史数据清空。

## 存储和同步

- 默认保存在当前浏览器的 localStorage，支持 JSON 备份导出和导入，不能仅靠 GitHub Pages 在电脑和手机自动同步。
- 已实现可选 Supabase 邮箱账号登录、定时同步、离线副本、冲突合并和删除标记，需先按 [SYNC_SETUP.md](SYNC_SETUP.md) 创建免费项目并运行数据库配置。默认配置为空，不会上传任何记录，也不会显示虚假的同步成功。
- 电脑和手机配置同一项目、登录同一账号后同步。账号数据与未登录数据分开保留，不同账号隔离。联网且页面可见时约每 15 秒拉取，修改约 0.8 秒后上传。
- 首次登录可选择合并本机原有数据。登录状态下导入备份采用合并，避免覆盖其他设备较新的数据；未登录时导入仍先确认替换。
- 浏览器清除站点数据会删除本地记录及离线副本，请先确认同步状态或导出备份。

## 验证范围

单元测试覆盖三态、时间区间、旧数据兼容、统计、同步合并、并发版本重试、认证刷新和错误处理。浏览器检查覆盖桌面/手机手势、任务编辑、模拟服务下的两个独立浏览器会话同步、离线恢复、删除传播及账号隔离。真实 Supabase 项目尚未提供，真实数据库的 RLS、邮件登录及设备往返同步需要接入后验证。

## 批量导入课表

「导入课表」支持按星期定义的 JSON 课表与含课表内容的导入链接。选择开始、结束日期（含首尾），预览后一次性追加到当前浏览器/登录账号；同日同名且起止时间相同的记录跳过，保留已有完成状态、个人任务、资产和开销。模板内容来自用户选择的文件或链接片段，不写入公共源码。链接片段只在浏览器解码；点击导入后移除片段，登录用户沿用原有同步流程。星期从周一 0 到周日 6，一次最多一年。

## 按周导航与视觉

电脑左侧为周列表，显示周日期、任务数和完成进度，包含已有任务所在的周；可继续加载更早/更晚的周或选择日期跳转。主看板始终按周展示七天并按开始时间排序。手机通过「选择周」打开左侧栏。标题经过统一规范化后确定彩虹渐变配色，同名任务跨日期、刷新后保持同色，完成状态仍为绿色小对号。切周、卡片悬停与点击完成有轻量动效，尊重系统减少动态效果设置。此更新不修改已有任务、开销或账号数据。

## 长按详情与短备注

短备注仍由普通任务表单的 `note` 字段编辑，直接以小字显示。详细备注独立保存在可选 `gptDetail: {source: "gpt", text: "…"}` 字段，不从普通短备注自动生成，也不在网页任务表单提供编辑框。

有详情的任务显示「长按详情」提示，长按约500毫秒后弹出浮起预览、模糊背景和只读详情。移动超过10像素、滚动或取消触摸会中止长按；长按不会切换完成状态。轻点仍完成/撤销，桌面也可右键或 Alt+Enter 查看，Esc、关闭按钮和点击背景可收起。长文本内部滚动，尊重系统减少动态效果设置。

通过本对话生成的 `#gpt-details=` 私人导入链接预览并更新已有任务，支持按任务ID或标题结合日期/时间/星期精确匹配（`weekdays` 中0为周一、6为周日），预览显示每条说明的匹配数量，保留完成状态和短备注；可选 `note` 才更新短备注。更新前保留本地备份，使用现有账号同步流程。长内容也支持 `#gpt-details-gz=` gzip 压缩链接，解压上限64KiB。普通课表解析器会剔除额外详情字段，完整备份则保留既有详情。来源标记用于区分界面入口，并非服务器认证或加密签名；本功能没有新增模型API连接。

专用导入内容示例（编码进链接片段，不放进公共源码）：

```json
{"kind":"planner-gpt-details","version":1,"entries":[{"match":{"title":"示例任务","start":"2026-11-08","end":"2026-12-10"},"text":"详细步骤\n第一步\n第二步"}]}
```

## 两周试行计划

`#trial-plan=` 接受 gzip/base64url 编码的私人 `planner-trial-import`（version 1）数据，日期含首尾且最多14天，按星期列出标题、起止时间、短备注和可选训练 `detail`。预览后加入实际任务，训练说明保存在独立 GPT 详情字段。相同日期、标题和时间的任务不重复添加，已有任务只更新匹配的训练详情，保留其短备注与完成状态；尊重删除标记，不删除区间外记录。时间重叠会提示核对。导入前保留本机 `.before-trial-import` 备份，随后沿用现有账号同步。个人课表和训练数据仅在私人链接中，不提交到公开仓库。
